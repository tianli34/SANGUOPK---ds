## 战斗机制：移动蓄力 + 射程外挥刀
- `Warrior.tick_ap` 去掉 `not is_moving` 判断：移动中也累积 AP（起手移动仍把 AP 归零，HUD 蓄力条因此会在跑动中填充）；移动中依旧不能出手。
- 新增空挥（whiff）：`BattleEngine._process_whiff`。前摇就绪但射程外/视线被挡时出手，只扣自身 SP（`constants.WHIFF_SP_COST_RATIO`）并进入后摇，对手不进入防守判定、不掉血。
- `run_tick` 不再用射程过滤 ready；拼刀只取真正够得着的一批（`clash_ready`），其余同 tick 各自空挥。
- 全链路支持新事件 `whiff`：`event_exporter`（actor/defender/whiff{distance,reach,spCost,reason}）、CLI 战报 `_format_whiff_log`、网页战报/动作栏、`Scene.whiff` 演出（只有刀光 + “落空”，无火花与伤害数字）。
- 实时操控 AP 面板新增 `inRange`：可出手但射程外时标题显示“射程外”，按 J 会提示“射程外 · 挥刀落空”。
- 200 场自动对战回归：AI 不会空挥（够不着时会先寻路，起手移动重置 AP），仅手动操控会出现；拼刀频率因入场 AP 差异变大而下降约 3 成（1012→715/200 场）。

## 网页版战斗计时器
- HUD 中央新增「用时」药丸（`web/index.html` 的 `#battle-clock` / `#clock-value`），按事件 `tick × 0.05`（对应 `src/constants.py` 的 `TICK_RATE`）显示 mm:ss。
- `web/js/app.js`：新增 `CLOCK_TICK_SECONDS`、`formatClock()`、`setBattleClock()`；时钟在 `setRoundTick()` 内更新，因此暂停停走、拖动进度条回退、重新播放归零都自动一致。
- 实时操控时事件是批量补播，`setRoundTick` 里用 `if (!Live.active)` 跳过时钟，改由 `livePoll` 用 `data.tick` 驱动，避免秒数回跳。
- 结果卡副标题增加总用时：「共 121 回合 · 用时 03:45（4514 tick）」。
- README §3 播放操作补了一条说明。本地用 `python main.py --serve-web` 起服务、内置浏览器截图核对过 00:00→03:45 与结束卡文案。
