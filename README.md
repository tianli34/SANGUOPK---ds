# SANGUOPK---ds

三国武将单挑模拟器：命令行战报 + 马战可视化网页版。

## 运行网页版

环境要求：Python 3.8+，仅使用标准库，无需安装第三方依赖。

### 1. 生成战斗数据（可选）

网页读取的是 `web/data/` 下的战斗事件文件。仓库中已有一份数据；想换一场战斗时，在项目根目录执行：

```bash
python main.py --export-web
```

指定随机种子以复现同一场战斗，或自定义双方武将属性：

```bash
python main.py --seed 89 --export-web
python main.py --a-name 马超 --b-name 许褚 --b-skill opening_ap_50 --export-web
```

该命令会同时写入 `web/data/battle.json` 与 `web/data/battle-data.js`（后者用于直接打开网页时的兜底加载）。

### 2. 启动网页

方式一：本地服务（推荐，支持「新的一局」）

```bash
# 在项目根目录执行
python main.py --serve-web
```

浏览器访问 <http://localhost:8000/>。页面上的「新的一局」会请求 `/api/battle`，用随机种子实时生成一场新战斗；默认只监听本机，可用 `--host` / `--port` 调整。

方式二：静态服务器（只能播放现有战局）

```bash
python -m http.server 8000
```

浏览器访问 <http://localhost:8000/web/>。没有动态接口，「新的一局」按钮不可用。

方式三：直接打开文件

双击 `web/index.html`。此时浏览器无法 `fetch` 本地 JSON，页面会自动回退读取 `web/data/battle-data.js`，效果一致。

### 3. 播放操作

- 「开始 / 暂停 / 继续」是同一个按钮：空闲时开始播放，播放中暂停或继续；播放结束后显示「已结束」。
- 「新的一局」用随机种子生成一场新战斗（需用 `python main.py --serve-web` 启动）。
- 「重新播放」从头播放当前这一局，「跳到结果」直接看胜负。
- 速度支持 1× / 2× / 4×。
- 拖动底部进度条可定位到任意事件；「上一步」或键盘 ← → 可逐条前后移动。
- 回退是按事件快照重建面板与战报，不是倒放动画；定位后按「继续」从该事件接着播。
- 右侧战报与左侧战场同步，显示每个事件的攻防判定、HP/SP/胆气变化与伤害。
- 战场上双方沿网格走位：进入射程才发起攻击，兵器射程不足时会先寻路接近（绕过岩石）。
- 「射程」按钮可高亮双方当前射程覆盖的格子（A 方金色、B 方蓝色，重叠为绿色），再次点击关闭。

### 4. 地图、射程与移动

- 默认地图为 13×7 的「演武场」：A 方出生于 (2,3)，B 方出生于 (10,3)，中央与两侧有岩石，岩石不可通行且阻挡攻击。
- 距离采用切比雪夫距离（八方向移动，每格 1 格距离）；攻击需要目标在兵器射程内且视线无遮挡。
- 射程按兵器类别：枪与矛 3 格、长柄大刀 2 格、戟 2 格、大斧与长柄锤 1 格、空手 1 格；单件兵器可在注册表中单独配置 `reach`。
- 移动速度为基础值 + 当前敏捷（随体力衰减）；起手移动会打断前摇，移动中不积累行动点且不能攻击，后摇期间无法起步。
- 战斗数据文档在启用地图时为 version 2：包含 `map` 地形、每个事件的站位 `position` 与 `move` 事件；未启用地图时仍为 version 1，行为与纯数值模拟完全一致。

## 命令行运行

```bash
python main.py                  # 单场单挑
python main.py -n 1000          # 批量模拟并输出汇总战报
python main.py --seed 89        # 指定随机种子，可复现
```

每次模拟的随机种子会记录在 `data/seed_history.json`，可凭种子复现结果。

## 目录结构

```
main.py              # 程序入口与命令行参数
src/                 # 战斗引擎、地图与寻路、战报、事件导出等核心逻辑
web/                 # 可视化网页
  index.html
  css/style.css
  js/app.js          # 播放控制、面板与战报同步
  js/scene.js        # 战场动画
  js/warrior-art.js  # 武将立绘绘制
  data/              # 由 --export-web 生成的战斗数据
tests/               # 测试
```
