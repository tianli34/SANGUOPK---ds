# SANGUOPK---ds

三国武将单挑模拟器：命令行战报 + 马战可视化网页版。

## 运行网页版

环境要求：Python 3.8+，仅使用标准库，无需安装第三方依赖。

### 1. 生成战斗数据（可选）

网页读取的是 `web/data/` 下的战斗事件文件。仓库中已有一份数据；想换一场战斗时，在项目根目录执行：

```bash
python main.py --export-web
```

指定随机种子以复现同一场战斗，或自定义双方武将属性：

```bash
python main.py --seed 89 --export-web
python main.py --a-name 马超 --b-name 许褚 --b-skill courage_floor_80 --export-web
```

也可直接选用内置名将预设，预设会覆盖该侧的名称、属性、特技与兵器：

```bash
python main.py --a-warrior 关羽 --b-warrior 赵云 --export-web
```

内置名将五维（参考《三国演义》战绩设定）：

| 名将 | 武艺 | 敏捷 | 力量 | 胆气 | 体力 | 兵器 |
|---|---|---|---|---|---|---|
| 赵云 | 97 | 97 | 92 | 99 | 98 | 龙胆亮银枪（枪矛，射程 1） |
| 马超 | 96 | 98 | 91 | 90 | 95 | 虎头湛金枪（枪矛，射程 1） |
| 许褚 | 91 | 88 | 99 | 91 | 99 | 血煞虎头刀（重型，射程 1） |
| 关羽 | 94 | 88 | 98 | 98 | 90 | 青龙偃月刀（重型，射程 1） |

#### 特技

特技分为**通用特技**与**专属特技**：通用特技任何武将都能装备，专属特技只能由归属武将装备。每个特技都带独立开关，关闭后不参与任何战斗结算。

| 特技 | 类型 | 归属 | 效果 |
|---|---|---|---|
| 临危不惧 | 通用 | — | 胆气始终不低于 80 |
| 武圣 | 专属 | 关羽 | 开局行动点数 +80；前 5 回合力量×2、敏捷×1.5、武艺=100，造成伤害×1.5~2.5；第 6 回合起恢复常态 |

预设装备：赵云、关羽装备「临危不惧」，关羽额外装备专属「武圣」。命令行可重复指定 `--a-skill/--b-skill` 装备多个特技；`--a-skill-off/--b-skill-off` 关闭开关，`--a-skill-on/--b-skill-on` 重新打开：

```bash
python main.py --b-warrior 关羽 --b-skill-off guan_yu_wusheng --export-web
python main.py --a-skill courage_floor_80
```

该命令会同时写入 `web/data/battle.json` 与 `web/data/battle-data.js`（后者用于直接打开网页时的兜底加载）。

### 2. 启动网页

方式一：本地服务（推荐，支持「新的一局」）

```bash
# 在项目根目录执行
python main.py --serve-web
```

浏览器访问 <http://localhost:8000/>。页面打开时会先请求 `/api/battle` 实时生成一场新战斗（不再显示上次导出的旧战局），「新的一局」打开配置弹层，选定武将与特技后带参数请求同一接口；默认只监听本机，可用 `--host` / `--port` 调整。

方式二：静态服务器（只能播放现有战局）

```bash
python -m http.server 8000
```

浏览器访问 <http://localhost:8000/web/>。没有动态接口，「新的一局」弹层会提示需启动本地服务，无法生成新战局。

方式三：直接打开文件

双击 `web/index.html`。若本地 8000 端口已运行 `--serve-web`，页面会自动跨域请求本地接口，每次打开都会生成一场新战斗；未运行时回退读取 `web/data/battle-data.js`（最后一次导出的战局）。使用自定义端口时请直接访问服务地址。

### 3. 播放操作

- 「开始 / 暂停 / 继续」是同一个按钮：空闲时开始播放，播放中暂停或继续；播放结束后显示「已结束」。
- 顶部中央的「用时」是战斗计时器：按当前事件的 tick 换算（1 tick = 0.05 秒），暂停时不走，拖动进度条或重新播放会跟着回退／归零；结束时结果卡同时列出总用时。
- 「新的一局」打开「点将 · 新局配置」弹层：A/B 两侧各选一名名将预设（展示五维与兵器），勾选装备特技并可切换启用/关闭；专属特技仅归属武将可选。点「开战」用随机种子生成新战斗（需用 `python main.py --serve-web` 启动），「恢复默认」回到命令行参数对应的配置。
- 「重新播放」从头播放当前这一局，「跳到结果」直接看胜负。
- 速度支持 1× / 2× / 4×。
- 拖动底部进度条可定位到任意事件；「上一步」或键盘 ← → 可逐条前后移动。
- 回退是按事件快照重建面板与战报，不是倒放动画；定位后按「继续」从该事件接着播。
- 右侧战报与左侧战场同步，显示每个事件的攻防判定、HP/SP/胆气变化与伤害。
- 战场上双方沿网格走位：兵器射程不足时会先寻路接近（绕过岩石）；没到射程也能挥刀，只是会落空。
- 「射程」按钮可高亮双方当前射程覆盖的格子（A 方金色、B 方蓝色，重叠为绿色），再次点击关闭。

### 4. 地图、射程与移动

- 默认地图为 13×7 的「演武场」：A 方出生于 (2,3)，B 方出生于 (10,3)，顶部整行、左上方与右下方为禁行边界（逻辑上不可通行且阻挡攻击，但不绘制石块）。
- 距离采用切比雪夫距离（八方向移动，每格 1 格距离）；攻击需要目标在兵器射程内且视线无遮挡。
- 射程按兵器类别配置，当前各类别默认均为 1 格、空手 1 格；单件兵器可在注册表中单独配置 `reach`。
- 移动速度为基础值 + 当前敏捷（随体力衰减）；移动中照样积累行动点，起手移动的瞬间打断前摇、AP 从零重攒，移动过程中不能出手；后摇期间无法起步，也不能出手。
- 射程外（或视线被地形遮挡）时同样可以挥刀，但只是空挥：对手不进入防守判定、不掉血，出手方照样付出出招体力并进入后摇；拼刀只在双方都真正够得着时成立。
- 战斗数据文档在启用地图时为 version 2：包含 `map` 地形、每个事件的站位 `position` 与 `move` 事件；未启用地图时仍为 version 1，行为与纯数值模拟完全一致。
- 战场底图：每场战斗按随机种子从 `battleField/` 的 51 张地形图中挑一张作为背景。素材按 1024 网格切成 `battleField_<ID>_0x<序号>.png` 若干块，网页用 canvas 拼回整图并按 cover 铺满舞台；随机选择与战斗共用同一随机流，同一种子可复现同一底图。素材约 68MB，已加入 `.gitignore` 不入库，缺失时自动回退为原有画面，格网与战斗逻辑不受影响。
- `battleField/` 由本地 `python main.py --serve-web` 通过 `/battleField/` 路由提供；静态服务器与直接打开 `index.html` 时使用相对路径 `../battleField/` 加载。

### 5. 武将精灵图

关羽、赵云、马超的战场形象与头像使用 `武将精灵图/<武将>` 中的 Cocos2d 图集。`tools/build_sprite.py` 会导出图集内的 5 个朝向（1 下、5 上、6 右上、7 右、8 右下），把每个朝向的待机、移动、攻击、受击硬直、阵亡帧裁切对齐成横向条带，并共用同一包围盒，切换朝向时单位大小不跳变：

```bash
# 开发期需要安装 Pillow；生成物已提交，运行网页仍只依赖标准库
python tools/build_sprite.py "武将精灵图/关羽" --name 关羽 --slug guanyu \
    --portrait "325,182,400,257"
python tools/build_sprite.py "武将精灵图/赵云" --name 赵云 --slug zhaoyun \
    --portrait "316,203,396,283"
python tools/build_sprite.py "武将精灵图/马超" --name 马超 --slug machao \
    --portrait "329,204,404,279"
```

- 生成 `web/assets/sprites/<slug>/{idle,run,attack,stuck,die}-<朝向>.png`、`portrait.png`，并合并写入 `web/data/sprites.js`。
- 战场按武将与对手的相对方位切换八方向条带：左、左上、左下复用右侧条带镜像；非地图模式仍默认朝右，B 方整体镜像。
- 前端按武将名称匹配精灵数据：待机循环、移动时播放跑步、攻击与反击播放挥砍、单次受伤超过最大体力 0.5% 播放受击硬直、阵亡播放落马；未提供精灵数据的武将仍使用 SVG 立绘。
- 播放速度与暂停跟随 `--beat` 与播放控件。
- 新增精灵武将时重复执行该命令即可（`--dirs` 可限定导出朝向，`--portrait` 可省略）。

## 命令行运行

```bash
python main.py                  # 单场单挑
python main.py -n 1000          # 批量模拟并输出汇总战报
python main.py --seed 89        # 指定随机种子，可复现
```

每次模拟的随机种子会记录在 `data/seed_history.json`，可凭种子复现结果。

## 目录结构

```
main.py              # 程序入口与命令行参数
src/                 # 战斗引擎、地图与寻路、战报、事件导出等核心逻辑
tools/               # 开发期资源工具（精灵图集打包）
web/                 # 可视化网页
  index.html
  css/style.css
  js/app.js          # 播放控制、面板与战报同步
  js/scene.js        # 战场动画
  js/warrior-art.js  # 武将立绘与精灵图渲染
  assets/sprites/    # 武将精灵图条带
  data/              # 战斗数据与精灵图配置（由脚本生成）
tests/               # 测试
```
